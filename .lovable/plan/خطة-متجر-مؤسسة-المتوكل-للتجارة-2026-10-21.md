# خطة متجر مؤسسة المتوكل للتجارة

متجر إلكتروني عربي (RTL) لبيع مواد البناء والعوازل، مع سلة، فاتورة بعد مراجعة المسؤول، دفع إلكتروني عبر Moyasar (مرتبط ببنك الراجحي)، وطلب عرض سعر على واتساب.

## اللي هيتعمل بالظبط

### 1. تفعيل Lovable Cloud (البنية الأساسية)

- قاعدة بيانات للمواد والطلبات، وحسابات للمستخدمين، وتخزين للملفات.
- كل حاجة بتبقى من غير حسابات خارجية.
- اعمل كمان اكونت للادمن يشوف ويوافق علي الطلبات واليوزر والباسوورد يكون 01018200812

### 2. قاعدة البيانات

- **التصنيفات** (4 أقسام): أدوات بناء أساسية – رولات العزل – أدوات اللياسة – الهوردي.
- **المنتجات** لكل قسم:
  - أدوات أساسية: مسمار عادي، مسمار صلب، سلك، شمبروم، نايلون، سلم بلك، زاوية بلك، بسكوت خرسانة، فيلر بورد.
  - رولات العزل: درع الخليج، درع الصحراء، مافكو (بمواصفات سماكة قابلة للتعديل).
  - اللياسة: زاوية اللياسة، شبك لياسة، شبك فايبر، وردة لياسة.
  - الهوردي: 4 مقاسات (25×40×200 / 30×40×200 / 35×40×200 / 40×40×200) بضغط 8، 10، 12، 14، 16، 18 = 24 منتج، + خيار "مقاس آخر" مخصص.
- أسعار تجريبية بالريال السعودي على كل منتج، تتبدل من لوحة التحكم.
- **الطلبات**: رقم طلب، حالة (جديد / قيد التحضير / بانتظار الدفع / مدفوع / مستلم)، بيانات العميل (اسم، موبايل، عنوان)، بنود الطلب بالكميات.
- **الشخص الإداري**: دور admin على الحسابات.

### 3. واجهة المتجر (عربي RTL)

- الصفحة الرئيسية: اسم المؤسسة + الأقسام الأربعة + منتجات مميزة.
- صفحة لكل قسم، وصفحة تفاصيل لكل منتج (المقاس والضغط للهوردي).
- سلة مشتريات (تتحفظ في المتصفح) + صفحة إتمام الشراء:
  - شرا كضيف: العميل يدخل اسمه وموبايله وعنوانه.
  - أو تسجيل حساب / تسجيل دخول (التاريخ محفوظ في حسابه).
- زر "طلب عرض سعر" يحول العميل على واتساب مسؤول المبيعات برسالة جاهزة فيها محتويات السلة.

### 4. مسار الفاتورة

1. العميل يضيف الأغراض والكميات للسلة ويرسل الطلب.
2. الطلب يوصل للوحة تحكم المسؤول (قائمة الطلبات + التفاصيل).
3. المسؤول يراجع ويعدل الكميات/الأسعار لو محتاج، ويغير الحالة.
4. عند التأكيد يتولد عرض الفاتورة صفحة منسقة، فيها زر "تحميل PDF" + زر إرسالها للعميل على واتساب.
5. العميل يشوف الفاتورة (برابط أو من حسابه) ويدفع إلكترونيًا.

### 5. الدفع الإلكتروني — Moyasar

- صفحة دفع عبر Moyasar (بطاقات مدى / فيزا / ماستركارد / Apple Pay) بأمان، والاستلام على حساب بنك الراجحي.
- المفاتيح (Test/Live) تتخزن كـ secrets مشفرة — محتاجين منك مفتاح API من لوحة Moyasar لما تجهز.
- عند تأكيد الدفع حالة الطلب تتبدل تلقائيًا لـ "مدفوع" ويبقى ممكن تحميل الفاتورة النهائية.
- لحد ما المفاتيح تضاف، الأزرار الدفعية تظهر بلطف لكن تعمل بالوضع التجريبي/غير المفعل.

### 6. لوحة تحكم المسؤول

- قائمة الطلبات الجديدة + التفاصيل + تغيير الحالة.
- إضافة/تعديل المنتجات والأسعار والمخزون.
- تعديل رقم واتساب مسؤول المبيعات من الإعدادات.

## التقنيات (قسم تقني)

- TanStack Start + React 19 + Tailwind v4، خط عربي (Tajawal أو Cairo) عبر link tag، `dir="rtl"`.
- صفحات: `/` الرئيسية، `/category/$slug`، `/product/$id`، `/cart`، `/checkout`، `/invoice/$orderId` (قابلة للطباعة PDF)، `/auth`، `/account` (طلباتي)، `/admin`.
- server routes: `/api/public/moyasar/callback` (تأكيد الدفع بعد التحقق من التوقيع).
- دمج Moyasar عبر `createServerFn` بسر إنشاء invoice وredirect على صفحة الدفع المستضافة.
- RLS: القراءة العامة للمنتجات فقط، والطلبات مخصوصة لصاحبها أو للـ admin.
